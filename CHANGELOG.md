# Changelog

Notable changes to Veyra are recorded here. The project is in active hackathon development; entries describe implemented behavior rather than promised integrations.

## 1.1.0 — 2026-10-18

### Added

- Embedded MCP server icon and setup-status diagnostics, including optional unpaid merchant probing.
- Exact upload-bundle tool discovery snapshots and Base/Solana proposal runtime tests.
- Portal setup and empty-capability troubleshooting guides.

### Fixed

- Cursor arrow tip and click ripple now target the exact center of the selected button in the product film.
- Refreshed the 33-second video locally with the current visual identity.

## Unreleased

### Changed

- Refined the geometric split-seal logo and added reusable SVG, outlined wordmark, PNG, and repository cover assets.
- Reorganized the README and documentation around setup, architecture, integration, contribution, and submission.
- Moved validation and rendering instructions to a local-only workflow.
- Standardized repository commit authorship and committer identity as Codex.

### Removed

- Hosted build, verification, and film-render workflow definitions.
- Unsupported registered-mark notation from current brand components.

## 1.0.0 — 2026-10-17

### Added

- Static Next.js collecting app with three original pack identities.
- Agent and manual demo modes, local allowance checks, persistent collection, and archive export.
- Public Pokémon TCG metadata with bundled offline references.
- Native PayBox plugin with four MCP tools and capped USDC x402 proposals.
- Exact amount validation, receipt deduplication, and uncertain-payment reconciliation handling.
- A 33-second Remotion product film using the supplied soundtrack and shared product components.
- Official plugin conformance checks and behavior tests.
